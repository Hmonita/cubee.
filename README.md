# CUBEE.IO — сервер

## Запуск
1. Установите Node.js 16+ (https://nodejs.org). Пакеты ставить не нужно.
2. В папке проекта: `node server.js` (другой порт: `PORT=8080 node server.js`)
3. Откройте http://localhost:3000 — под кнопкой СТАРТ будет окно «Амстердам (N/10)».

## Как выложить для других игроков
Запустите `node server.js` на VPS (например, в дата-центре в Амстердаме) и откройте порт.
Для HTTPS поставьте перед сервером nginx/Caddy с проксированием, включая WebSocket (путь `/ws`).

## Настройки
- Максимум игроков, название сервера и частота обновлений — вверху `server.js` (`MAX_PLAYERS`, `SERVER_NAME`, `TICK_MS`).
- Если `index.html` лежит отдельно от сервера, в `public/index.html` в массиве `SERVERS` укажите `url:'https://ваш-домен'`.
- Чтобы добавить ещё серверы — добавьте элементы в `SERVERS` (запустите отдельный `server.js` на каждый).

## Что синхронизируется
Игроки (позиция, ник, предмет в руке, HP), чат, рейтинг по золоту, счётчик игроков.
Мир одинаковый у всех при входе (фиксированный seed), но деревья/камни/блоки/предметы
пока считаются у каждого игрока локально и не синхронизируются.
